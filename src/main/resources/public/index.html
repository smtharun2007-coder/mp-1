Infrastructure & Operational Cost Analysis

Operates entirely on the free MongoDB Atlas M0 cluster tier and standalone lightweight Java 17 runtime ($0.00 cloud operational cost).

System Architecture & Algorithmic Complexity

1. Multi-Criteria Priority Queue

Built with java.util.PriorityQueue using a composite Comparator: Severity DESC → Population DESC → ArrivalNo ASC. Insert & poll run in O(log n). Dynamic updates use remove(req) then add(req) in O(n).

2. Graph Routing & Reachability

Undirected graph stored as an adjacency list HashMap<Integer, List<Edge>>. Skips closed roads during construction. BFS and DFS reachability traversals run in O(V + E). Dijkstra shortest path runs in O((V + E) log V) using a min-heap.

3. Two-Layer Concurrency & Atomic Reservations

Layer 1: In-process synchronized lock around AllocationService.commit() preventing local thread interleaving.
Layer 2: MongoDB multi-document ACID transactions (ClientSession.withTransaction) combined with conditional update filters ({$gte} for stock, {$expr: {$gte: [{$subtract: ["$capacity", "$reserved"]}, qty]}} for shelters). Physical double-promising is impossible.

4. Unified Single Assessment Form & Need-First Tie-Breaking

Field officers submit one form per affected region containing all needs (Rescue, Shelter, Medicine, Food) and a Need-First ranking sequence. When approved, two linked requests (RescueRequest and SupplyRequest) are created. Whichever request satisfies the #1 ranked need is assigned the first arrivalNo sequence, guaranteeing it wins the queue tie-breaker against the sibling request from the same region.

5. START Mass-Casualty Triage & Honest Labelling

HONEST LABELLING STATEMENT:
  • Triage categories follow the adult START (Simple Triage and Rapid Treatment) mass-casualty method. START is an international first-responder protocol, not an official Government of India system, and must be performed by a responder physically at the scene. Remote operators cannot diagnose casualties.
  • Thresholds (≥5 Red = Level 5, etc.) and relief kit ratios (1 med kit / 10 people, 1 food pack / 5 person-days) are project assumptions configured in SeverityConfig.
  • L1/L2 escalation levels are adapted from national disaster management concepts.
